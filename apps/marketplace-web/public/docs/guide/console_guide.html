适用用户：企业管理员、财务主管、开发团队负责人

2. 核心操作流程 ​

2.1 步骤一：创建部门与配置多级预算 ​

  1. 登录控制台，进入左侧导航 「组织与部门」；
  2. 点击 「新建部门」，输入部门名称（如“智能客服事业部”）与负责人联系方式；
  3. 为该部门划拨 月度预算额度（如 ¥20,000）；
  4. 当部门下辖所有 Agent 累计消耗达到预算 80% 时，系统自动向负责人推送预警；达到 100% 时自动开启熔断阻断。

2.2 步骤二：接入飞书 / 企业微信审批机器人 ​

  1. 进入左侧导航 「安全与审批 (HITL)」 $\to$ 「审批通道配置」；
  2. 选择 飞书（Feishu） 或 企业微信（WeCom）；
  3. 填入企业机器人的 Webhook URL 与 Secret；
  4. 配置审批触发阈值：
    • 自动放行上限：例如 $\le 1.00$ 元；
    • 人工审批阈值：大于 $1.00$ 元且 $\le 100.00$ 元；
    • 单笔硬阻断上限：大于 $100.00$ 元。

2.3 步骤三：财务充值与对账单导出 ​

  1. 进入 「财务中心」 $\to$ 「钱包与充值」；
  2. 选择充值金额（如 ¥5,000），页面动态生成微信支付 / 支付宝收款码；
  3. 扫码支付完成后，账务中心通过 Webhook 毫秒级原子入账，系统按 6 位微单位换算到企业虚拟账本；
  4. 月末可在 「财务账单」 中一键导出按部门拆分的对账 CSV 清单，并直连数电发票系统开具增值税专票。

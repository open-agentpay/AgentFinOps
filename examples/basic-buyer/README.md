# Basic Buyer Example

This example demonstrates how an autonomous AI agent uses the `agent-core-sdk` Python client to consume enterprise APIs protected by AgentFinOps.

## Key Capabilities Demonstrated:
- Client authentication and credential management (`AgentCoreClient`)
- Local budget control policy configuration (`PolicyConfig`)
- Transparent quota verification & token metering negotiation
- Automatic quota reservation and commit

## Usage:
```bash
python main.py
```

> **说明**：本文档为 AgentPay 全局唯一技术路线图，全面聚焦于企业生产环境中大模型与 AI Agent 的行为审计、资金防火墙、组织树状配额切分、人在回路 (HITL) 协同审批、合规在线预付与发票闭环，**以生产级架构完备性与企业级交付为唯一标准**。

## 2. 四大核心任务模块详情

### 模块一：企业级安全防御与人在回路（Enterprise Security & HITL）

#### 1.1 办公协同与人在回路（Human-in-the-Loop, HITL）审批
- **三级风控梯度**：
  - **小额**（$\le$ 阈值）：本地策略毫秒级极速放行；
  - **中大额**：触发外部协作平台人工审批；
  - **超大额**：触发单笔硬顶阻断（`SINGLE_TX_CAP_EXCEEDED`）。
- **402 异步挂起与解挂机制**：网关返回 `402 Payment Required` 与 `approval_id`，避免 HTTP 长连接阻塞，后台异步向负责人的**飞书 / 企业微信 / 钉钉**推送富文本审批卡片。
- **移动端一键放行**：审批卡片显示 Agent 身份、触发意图、预计消耗与归属部门；负责人点击批准后，客户端 SDK 自动携带凭证重放，网关原子执行 Hold 冻结与后续调用。

#### 1.2 进程外隔离 Sidecar 守护进程（防御 N6 威胁）
- **痛点解决**：在现有嵌入式 SDK 模式下，LLM 运行时与 SDK 共享宿主进程。若工具具备任意代码执行能力，存在进程内存窃取或绕过拦截器的风险。
- **架构方案**：将金融防火墙与签名器下沉为独立的**本地 Sidecar 守护进程**（或轻量 Docker/Unix Domain Socket），以独立低权限 OS 用户运行，主 Agent 仅能通过 IPC 发起支付意图。

#### 1.3 云端 KMS 与国密 HSM 硬件安全签名（防御 N1 威胁）
- **核心功能**：买方与网关凭据脱离本地明文存储与环境变量。
- **集成支持**：
  - 接入阿里云 KMS、腾讯云 KMS、AWS KMS、Google Cloud KMS；
  - 针对金融与政企合规客户，支持国密硬件加密机（HSM）与 PKCS#11 硬件令牌进行签名。

#### 1.4 智能行为异动检测与自适应熔断（Anomaly Detection）
- **频次与分布建模**：在传统固定 RPM 熔断之外，构建基于滑动窗口的请求频次与单价消耗基线模型。
- **渐进式响应**：首次偏离基线触发警告日志；持续偏离自动切断流量，并将该 Agent 的 API Key 降级或置入临时观察区。

### 模块二：AI FinOps、合规资金与企业财务闭环（FinOps & Compliance）

#### 2.1 树状组织多层配额体系
- **四级成本切分架构**：**租户（企业/组织） $\to$ 事业群/部门 $\to$ 项目组 $\to$ 具体 Agent**。
- **配额管理**：支持“父节点总预算硬顶 + 子节点按月/按季分配额度”；支持预算耗尽自动降级或拦截。

#### 2.2 国内合规在线充值体系
- **双阶段防“二清”合规路线**：
  - **阶段一（自营与平台聚合预付）**：资金入平台对公账户，换算为内部不可提现、不可跨租户互转的虚拟账本微单位，纯属于算力与 API 预售，零金融牌照风险；
  - **阶段二（多商户撮合清分）**：接入持牌机构（微信电商收付通、支付宝直付通、商业银行专用账户），网关仅下发清分指令，资金不过平台账户。
- **入账精度换算**：外部渠道以人民币“分”（两位小数）交互，入账边界严格执行 $\text{amount\_base\_units} = \text{payment\_minor\_amount} \times 10,000$，转为 6 位微单位整数存储，全程严禁浮点数。
- **充值双层幂等防重放**：`external_ref` 与 `topup:{id}` 组合唯一索引，防止三方 Webhook 重试造成重复入账。

#### 2.3 财务核销、对账单与数电发票集成
- **日终自动平账**：自动核对支付渠道账单流水、网关账本变动与上游履约记录。
- **合规发票闭环**：支持月度消费账单导出（包含按部门拆分的调用流水），直连数电发票接口，一键开具增值税普票或专票。

### 模块三：微计费引擎与分布式清算架构（Micro-Metering & Distributed Settlement）

#### 3.1 毫秒级 Token 流式微计费与动态单价折算
- **核心逻辑**：流式调用场景下（SSE Chunk-by-Chunk 解析），在传输过程中实时计量 Prompt 与 Completion Token；
- **技术实现**：
  - 基于模型定价字典动态预估最大额度并在请求前 Hold；
  - 流式响应结束后，网关根据真实 Token 消耗精确核算（Capture），毫秒级释放多余预留（Release），杜绝额度悬挂与资金浪费。

#### 3.2 高频批量记账缓冲与聚合落盘 (Batch Settlement Buffer)
- **适用场景**：面向企业数千并发智能体的高频微额调用场景，降低数据库单笔写入开销。
- **技术实现**：
  - 网关在本地内存原子验证配额并记录账单事件；
  - 采用滑动时间窗口与微批量聚合机制，批量事务性写入底层不可变账本（`ap_ledger_entry`），将数据库 I/O 写入压力降低 90% 以上。

#### 3.3 高可用分布式网关集群
- **分布式配置同步**：将现有基于内存的单机 RCU 升级为基于 Raft 或 Redis/etcd 协同的分布式事件总线，实现跨多实例路由规则、Key 状态与配额的秒级同步；
- **五重对账引擎调度器（Five-Way Reconciliation Scheduler）**：独立常驻的离线对账巡检器，跨节点排查并自动平账非终态悬挂订单。

### 模块四：开放生态、全语言 SDK 与开源联动（Ecosystem & DevEx）

#### 4.1 MCP（Model Context Protocol）协议原生支持
- **标价中间件**：为 Anthropic MCP Server 提供开箱即用的支付拦截插件，使任何本地或远程 MCP 工具具备一键声明价格的能力；
- **客户端防火墙**：在 MCP Client 端自动注入 AgentPay 金融防火墙，智能解析 Tool Call 入参并进行额度预检。

#### 4.2 与开源 Observability（Langfuse）深度共生
- **定位分工**：明确不重复研发 Prompt 管理工具，与 MIT 协议开源顶流 Langfuse 组成**「AI 运维双子星」**：
  - **Langfuse 管“大脑”**：负责 Prompt 追踪、Token/Embedding 监控、LLM 评分与评估；
  - **AgentPay 管“双手”**：负责拦截外部真实金钱交易、物理切断死循环、保障不可篡改审计定责。
- **无缝打通**：在 AgentPay 审计流中自动关联 Langfuse 的 `trace_id` 与 `span_id`，实现“输入 Prompt $\to$ 模型思考 $\to$ 付费调用 $\to$ 真实扣款”的全链路联合排查。

#### 4.3 多语言客户端与卖方中间件生态补全
- **Java / Spring Boot Starter**：面向大型金融、电信及政企后端技术栈，提供注解式权限与防火墙 SDK（`@AgentPayGuard`）；
- **Node.js / Web 卖方中间件**：发布 Express、Fastify、NestJS 中间件，供 API 卖方一行代码接入计费与防火墙验证；
- **Python / TS SDK 持续演进**：深化与 LangChain、Dify、CrewAI、AutoGen 及 Vercel AI SDK 的深度适配。

#### 4.4 推动企业级 AI 行为审计与资金防火墙标准
- 提炼企业级 AI 网关的三态状态机规范与 Header 协议；
- 推动将支持企业虚拟账本两阶段挑战与人在回路审批的防护标准提交为行业标准规范。
